═══════════════════════════════════════════════════════════════════
📋 HƯỚNG DẪN SETUP BUFF SYSTEM (INCREASE ATTACK & DEFENSE)
═══════════════════════════════════════════════════════════════════

TỔNG QUAN:
- Increase Attack: Tăng 40% ATK cho từng nhân vật
- Increase Defense: Tăng 60% DEF cho từng nhân vật
- Buff giảm 1 stack mỗi turn (stack = thời gian tồn tại)
- UI hiển thị CHUNG cho TOÀN TEAM (1 container duy nhất)

═══════════════════════════════════════════════════════════════════
BƯỚC 1: TẠO BUFF ICON PREFAB
═══════════════════════════════════════════════════════════════════

1. Tạo Canvas tạm (nếu chưa có)
2. Chuột phải Canvas → UI → Image
   - Tên: "BuffIcon"
   - Size: 40x40

3. Tạo children:
   a) Background (Image):
      - Stretch full parent
      - Color: Vàng với Alpha = 0.7 (khác với debuff màu đen)
   
   b) Icon (Image):
      - Size: 35x35, Center
      - Màu trắng
   
   c) StackText (TextMeshPro):
      - Size: 20x20
      - Anchor: Bottom Right
      - Pos X: -5, Pos Y: 5
      - Font Size: 16
      - Color: Trắng
      - Bold

4. Add Script:
   - Chọn BuffIcon GameObject
   - Add Component → "BuffIcon"
   - Assign:
     * Icon Image → Kéo "Icon" vào
     * Stack Text → Kéo "StackText" vào

5. Kéo "BuffIcon" từ Hierarchy vào Project để tạo Prefab
6. Xóa Canvas tạm khỏi Scene


═══════════════════════════════════════════════════════════════════
BƯỚC 2: SETUP BUFF CONTAINER CHO TEAM ⭐ QUAN TRỌNG
═══════════════════════════════════════════════════════════════════

**CHỈ CẦN 1 CONTAINER DUY NHẤT CHO TOÀN TEAM**

1. Tìm PlayerTeam GameObject trong Scene (thường ở Hierarchy)

2. Tạo World Space Canvas:
   ─────────────────────────
   - Chuột phải PlayerTeam → UI → Canvas
   - Tên: "TeamBuffCanvas"
   - Trong Inspector:
     * Render Mode: World Space
     * Width: 300
     * Height: 50
     * Position X: 0
     * Position Y: -0.8 (điều chỉnh để ở DƯỚI thanh máu team)
     * Position Z: 0
     * Scale X: 0.01
     * Scale Y: 0.01
     * Scale Z: 0.01

3. Tạo Buff Container:
   ────────────────────
   - Chuột phải TeamBuffCanvas → UI → Empty
   - Tên: "BuffContainer"
   - Rect Transform:
     * Anchor Presets: Stretch (all sides)
     * Left: 0, Right: 0, Top: 0, Bottom: 0
   - Add Component → Horizontal Layout Group:
     * Spacing: 5
     * Child Alignment: Middle Center
     * Child Control Size: UNCHECKED (tất cả)
     * Child Force Expand: UNCHECKED (tất cả)

4. Add TeamBuffManager Script vào PlayerTeam:
   ───────────────────────────────────────────
   - Chọn PlayerTeam GameObject
   - Add Component → tìm "TeamBuffManager"
   - Trong Inspector của TeamBuffManager:
     * Buff Icon Container → Kéo "BuffContainer" vào
     * Buff Icon Prefab → Kéo "BuffIcon" prefab từ Project vào

5. Lưu Scene

**⚠️ LƯU Ý: KHÔNG CẦN setup BuffContainer cho từng player riêng lẻ nữa!**


═══════════════════════════════════════════════════════════════════
BƯỚC 3: TẠO CARD EFFECTS
═══════════════════════════════════════════════════════════════════

1. Increase Attack Effect:
   ────────────────────────
   - Chuột phải trong Project → Create → Card Effects → Increase Attack
   - Tên: "IncreaseAttackEffect" (hoặc "BattleCryEffect")
   - Trong Inspector:
     * Cast Name: "Battle Cry" (hoặc tên khác)
     * Buff Stacks: 3 (tồn tại 3 turns)
     * Buff Icon: Kéo sprite icon tăng ATK vào (⚔️ hoặc icon phù hợp)

2. Increase Defense Effect:
   ─────────────────────────
   - Chuột phải trong Project → Create → Card Effects → Increase Defense
   - Tên: "IncreaseDefenseEffect" (hoặc "ShieldWallEffect")
   - Trong Inspector:
     * Cast Name: "Shield Wall" (hoặc tên khác)
     * Buff Stacks: 3 (tồn tại 3 turns)
     * Buff Icon: Kéo sprite icon tăng DEF vào (🛡️ hoặc icon phù hợp)


═══════════════════════════════════════════════════════════════════
BƯỚC 4: TẠO CARDS
═══════════════════════════════════════════════════════════════════

1. Increase Attack Card:
   ─────────────────────

   - Tên: "BattleCryCard"
   - Trong Inspector:

2. Increase Defense Card:
   ──────────────────────
   - Chuột phải Project → Create → Card Game → CardData
   - Tên: "ShieldWallCard"
   - Trong Inspector:
     * Card Name: "Shield Wall"
     * Type: Cast
     * Artwork: Kéo sprite artwork vào
     * Effect: Kéo "IncreaseDefenseEffect" vào
     * Description: "Tăng 60% DEF cho cả đội trong 3 turns"


═══════════════════════════════════════════════════════════════════
CÁCH HOẠT ĐỘNG
═══════════════════════════════════════════════════════════════════

INCREASE ATTACK:
────────────────
- Hiệu ứng: +40% ATK (cố định)
- Stack: Thời gian tồn tại (không nhân hiệu ứng)
- Ví dụ: Player có 100 ATK
  * Apply 1 lần (3 stacks): 140 ATK trong 3 turns
  * Apply 2 lần (6 stacks): 140 ATK trong 6 turns
  * Mỗi turn: Giảm 1 stack, stack = 0 → buff hết

INCREASE DEFENSE:
─────────────────
- Hiệu ứng: +60% DEF (cố định)
- Stack: Thời gian tồn tại (không nhân hiệu ứng)
- Ví dụ: Player có 20 DEF
  * Apply 1 lần (3 stacks): 32 DEF trong 3 turns
  * Apply 2 lần (6 stacks): 32 DEF trong 6 turns
  * Mỗi turn: Giảm 1 stack, stack = 0 → buff hết

**UI CHUNG CHO TEAM:**
- Tất cả buff hiển thị trong 1 container duy nhất
- Mỗi loại buff chỉ hiện 1 icon (không duplicate)
- Stack hiển thị = stack cao nhất trong team
- Vị trí: Dưới thanh máu team

═══════════════════════════════════════════════════════════════════
GỠ LỖI
═══════════════════════════════════════════════════════════════════

❌ Buff không hiện lên:
   → Kiểm tra TeamBuffManager đã add vào PlayerTeam chưa
   → Kiểm tra BuffContainer và Prefab đã assign đúng chưa
   → Xem Console log có error không
   → Test: Chơi card buff và xem log

❌ Buff icon hiện ở giữa màn hình:
   → TeamBuffCanvas phải là World Space (không phải Screen Space)
   → Scale phải là 0.01, 0.01, 0.01
   → BuffContainer phải là con của TeamBuffCanvas

❌ Icon hiển thị sai vị trí:
   → Điều chỉnh Position Y của TeamBuffCanvas
   → Kiểm tra BuffContainer có Horizontal Layout Group
   → Child Alignment = Middle Center

❌ Buff không tăng stats:
   → Kiểm tra Console log xem buff có được apply không
   → PlayerCharacter.GetATK() và GetDefense() đã được update
   → Test: So sánh damage trước và sau khi buff

❌ Stack không giảm:
   → BattleManager phải gọi ProcessBuffsAtTurnStart()
   → Kiểm tra log mỗi turn

❌ Icon không có sprite:
   → Buff Icon trong Effect phải được assign
   → Kiểm tra sprite đã import đúng (Texture Type = Sprite)
